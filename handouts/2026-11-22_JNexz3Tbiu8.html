Build the atelier before the factory: models improved exponentially on an unchanged harness while human attention and maintenance did not scale, so spend the surplus on excellent, ambitious software.

TL;DR

  • Model upgrades, not harness engineering, delivered the year's capability gains on an unchanged Pi harness; most prompting tricks became unnecessary.
  • Human attention did not scale: starting projects got fast while finishing and maintenance did not, and maintained projects stayed flat as starts accumulated.
  • Evolve the harness where it pays — durable suspend-resume, codemode, cheap classifier models — to keep runs alive and context lean.
  • Spend the surplus on excellence: verified, faster, memory-safe (Rust) software, not mass-produced slop — 'we can build anything, but should we?'

Deep dives

[01:21] A stable harness absorbed a year of model progress

  • Pi's core harness is unchanged in a year; same tools today as December last year.
  • Most prompting ideas were replaced by better models; the Pi Auto Research plugin is no longer necessary with present-day state-of-the-art models.

Why it matters: Design for model-driven capability: keep the harness thin, and re-audit prompt tricks each model generation instead of accumulating scaffolding. (inference)

Watch out: Single-user evidence from the harness's vendor; other harnesses may still need their tricks.

[04:37] The human did not

  • Human attention is the limiting factor; we do not have more humans.
  • Starting projects got incredibly easy; maintaining them did not get easier.
  • Agents tax systems never meant for it: GitHub, npm, random third-party websites.

Why it matters: Size agent rollouts by review, finishing and maintenance capacity, not generation throughput; downstream systems need load checks too. (inference)

Watch out: External-system strain is slide assertion plus anecdote; no request volumes measured.

[07:57] Workshop discipline: pushback, true skill, moderated speed

  • Know when to tell the agent 'not like this' and redirect it.
  • True skill versus agent skill: experienced engineers get different results working with the same agent.
  • Moderate speed by understanding: he prompts for a short executive summary and a typeset HTML page before verification.

Why it matters: Readable intermediate artifacts keep human judgment attached to long runs; otherwise agents assemble a 'Simpson car' of mismatched features. (inference)

Watch out: Personal practice; no measured comparison of skilled versus unskilled users.

[11:12] Wildwuchs: resist uncontrolled bespoke growth

  • He prefers few dependencies, yet warns 'Wildwuchs' — uncontrolled growth — harms interoperability.
  • Open protocols, specifications and file formats let humans and tools work together; a crafted tar archive is read differently by different tar implementations.
  • Collaboration between humans remains human slow, itself slowing things down.

Why it matters: Anchor agent-written code to shared protocols and formats; bespoke glue multiplies one-off integration surfaces. (inference)

Watch out: Argument with anecdote; standards alignment still costs human-slow coordination time.

[15:02] Harness evolution: durability, codemode, classifier models

  • Durable workflows outlive the process and human attention: start, stop, suspend, come back; humans answer in hours.
  • Codemode runs agent-composed JavaScript and bash harness-side; loops and concurrency bypass the context; state lives in the transcript.
  • Classifier models (Jev, Chef) return choices and scores, not prose, called from codemode loops to crunch squishy human tasks.

Why it matters: Cost and latency levers: suspend through idle token windows for flexible-scheduling discounts on raw token cost; move bulk judgment off the context path. (inference)

Watch out: Discount size, classifier accuracy and throughput unquantified; the support-triage example is illustrative, not measured.

Where it breaks

  • Agent output outruns reviewer comprehension; changes land faster than anyone can push back. (inference)
  • Bespoke agent-written glue proliferates; interoperability decays and integrations become one-off. (inference)
  • Long runs lose state on process restart or hours-long human waits without durable suspend-resume. (inference)
